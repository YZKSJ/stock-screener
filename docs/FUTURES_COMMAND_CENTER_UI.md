# Orbital Futures Desk UI

This page is a visual shell for the existing commodity-futures research workflow. The center particle vortex is an animated Canvas illustration, not a market model or trading engine. Price labels, module gauges, evidence matrix, risk gauges, metrics, code and event log in the upper shell are illustrative sample values and are prominently labeled as demo/offline. The original API-backed contract directory and daily research form remains available below the shell.

The page does not submit orders or connect to a brokerage account. Do not interpret the sample figures as market prices, computed signals, probabilities, execution logs, or risk advice.
